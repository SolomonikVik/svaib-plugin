# Прогресс — как двигался объект управления

## Имя и место

`04_progress.md` (номер может отличаться) в папке объекта управления: компании, направления, проекта, клиента и других.

## Миссия

Прогресс показывает, как двигался объект: что реально изменилось относительно его цели. По нему видна динамика за неделю, квартал и всю историю — без чтения встреч.

## Основные блоки

Записи, свежее сверху. Одна запись — один предмет: результат, к которому идёт движение, — «фундамент», «первый этаж», «пилот».

- Заголовок — период и предмет. У записи из одной строки — одна дата.
- Под заголовком — строки, по одной на событие, по порядку событий: дата, что сдвинулось, источник. Источник — ссылка на выжимку встречи или на файл-результат; ссылки нет — словом в скобках: «(переписка)», «(звонок)», «(разговор с партнёром)».

Образец:

```markdown
## 2026-03-09 – 2026-03-24 · Первый этаж
- 2026-03-09 — бригада поставила рекорд кладки за смену. (переписка)
- 2026-03-12 — стены первого этажа выведены. [Выжимка встречи](meetings/2026-03-12_general/summary.md)
- 2026-03-24 — перекрытие уложено, этаж готов на неделю раньше графика. [Выжимка встречи](meetings/2026-03-24_general/summary.md)

## 2026-03-02 · Фундамент
- 2026-03-02 — фундамент залит и принят без замечаний. [Выжимка встречи](meetings/2026-03-02_general/summary.md)
```

## Что в файл не идёт

- Работа над файлами: обновили, переименовали, навели порядок, подкрутили. Исключение — когда файл и есть результат: «собрано позиционирование».
- То, что выводится из уже записанной строки: после «первый этаж готов» кирпичи и окна не пишутся.
- Встреча или переписка, которые ничего не сдвинули. Кто был на встрече и что обсуждали — в её выжимке.
- Где объект сейчас — в обзоре (`overview`); задачи и планы — в активе и бэклоге (`active`, `backlog`).
- Мотив и альтернативы решения — в журнале решений (`decisions`).

## Правила записи

1. Перед записью прочитай обзор объекта — его цель и масштаб — и записи за последний месяц; запись того же предмета ищи по заголовкам всего файла.
2. Записывай то, что имеет самостоятельный вес для движения объекта к цели, в том числе срыв: «сдача сдвинута на месяц: поставщик сорвал поставку». Вес зависит от объекта: для дома замена кирпича — шум, для проекта «купить три кирпича» каждый кирпич записывается.
3. Новое событие по предмету записи — новая строка в ней; уточнение уже записанного — правка его строки. Достигнутый результат — последняя строка записи, без отметок о закрытии.
4. Добавив строку, продли период в заголовке и поставь запись по её последней дате.
5. Дата строки — дата события, а не дня записи.
