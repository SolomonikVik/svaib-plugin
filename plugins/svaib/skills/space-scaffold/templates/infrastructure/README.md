# infrastructure — шаблоны служебных папок

Шаблоны служебных папок scaffold: входящее до разбора и холодный контекст. Эти папки помогают агенту не смешивать неразобранное, актуальную память и архив.

## Содержимое папки

- [_входящее/](./_входящее/) — входящее до разбора. Читать: когда узлу нужно своё место для неразобранного.
- [_архив/](./_архив/) — холодный или завершённый контекст. Читать: когда узлу нужен свой архив.

## Правила работы

- Служебные папки не являются управленческими узлами. В них нет `AGENTS.md` и `CLAUDE.md`; агент читает локальный README папки, чтобы понять роль контейнера.
