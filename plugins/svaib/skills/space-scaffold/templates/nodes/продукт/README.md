# продукт — продукт как объект управления

Особый корневой объект управления для продукта компании: что поставляется клиентам, как устроено, куда развивается и как управляется.

Канон продукта как объекта управления в проработке. Базово продукт — постоянный объект управления: то, что компания поставляет клиентам, а не временный проект.

## Содержимое папки

- [_вводная.md](_вводная.md) — вводная продукта: что это, кто отвечает, куда идёт и почему. Читать: при первичном входе в продуктовый контекст.
- [паспорт.md](паспорт.md) — паспорт продукта: позиционирование, портрет клиента, границы, бизнес-модель. Читать: при вопросах о сути продукта и его рынке.

## Связанные контексты

- `../00_компания/` — компания как целое, если продукт связан с общим курсом, метриками или командой

## 🔧 Разворачивание

- `_делаем.md` — появилась текущая работа
- `_планы.md` — появились отложенные задачи и идеи
- `_хроника.md` — стоит записать, что происходило
- `_решения.md` — первое зафиксированное решение
- `архитектура.md` — внутреннее устройство продукта стало важно для управления
- Папки управления (`00_стратегия/`, `00_команда/`, `00_показатели/`, `00_проекты/` и др.) — когда появилась работа по ракурсу: сразу папкой, даже ради одного файла
- Служебные папки (`_входящее/`, `_архив/`) — по своему потоку
- `_встречи/` — правило встреч из корневого README размещает встречи здесь
- Рабочие папки клиента (`docs/` и др.) — появились рабочие материалы
