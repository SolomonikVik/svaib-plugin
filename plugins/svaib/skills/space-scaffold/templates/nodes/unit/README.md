# unit — универсальный объект управления

Универсальная папка объекта управления: функции, филиала, подразделения, бизнес-направления или родительского объекта.

## Содержимое папки

- [_вводная.md](_вводная.md) — вводная объекта управления: что это, кто отвечает, куда идёт и почему. Читать: при первичном входе в папку.

## Связанные контексты

- Заполняется при разворачивании: родительская папка, смежные объекты управления и контекст уровня компании, если они нужны для чтения этого объекта.

## 🔧 Разворачивание

- `_делаем.md` — появилась текущая работа
- `_планы.md` — появились отложенные задачи и идеи
- `_хроника.md` — стоит записать, что происходило
- `_решения.md` — первое зафиксированное решение
- Папки управления (`00_стратегия/`, `00_команда/`, `00_показатели/`, `00_финансы/`, `00_проекты/`, `00_процессы/`) — когда появилась работа по ракурсу: сразу папкой, даже ради одного файла
- Служебные папки (`_входящее/`, `_архив/`) — по своему потоку
- `_встречи/` — правило встреч из корневого README размещает встречи здесь
- Рабочие папки клиента (`docs/`, `contracts/` и др.) — появились рабочие материалы
