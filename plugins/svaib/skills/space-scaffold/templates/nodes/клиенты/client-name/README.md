# client-name — клиентский проект

Папка одного внешнего клиентского проекта: бизнес контрагента, что делаем, текущая работа, хроника и решения.

## Содержимое папки

- [_вводная.md](_вводная.md) — вводная клиентского проекта: что это, кто отвечает, куда идёт и почему. Читать: при первичном входе в проект.
- [компания.md](компания.md) — бизнес контрагента: продукт, цифры, люди, стратегия. Читать: при подготовке решений и материалов по проекту.
- [люди.md](люди.md) — люди контрагента: роли, влияние, позиция, стиль коммуникации. Читать: перед встречей и перепиской.

## Маршруты чтения

- Быстро войти в проект → `_вводная.md`
- Подготовиться к встрече → `_вводная.md` → `люди.md`
- Понять людей контрагента и коммуникацию → `люди.md`
- Понять бизнес контрагента → `компания.md`

## Маршруты записи

README маршрутизирует уже выбранный факт. Если информация не ложится в миссию файла, оставь её во входящем `_входящее/` до разбора.

- Факт о человеке, роли, влиянии, стиле коммуникации → `люди.md`
- Факт о бизнесе контрагента: продукт, цифры, стратегия, оргструктура, технологии → `компания.md`; люди в оргструктуре — ссылками на `люди.md`
- Рамка проекта: суть, цель и на какую цель работает, как двигаемся, команда, условия → `_вводная.md`; вехи → `_планы.md`

## Связанные контексты

- `../` — клиентский портфель, если проект нужно читать в контексте других клиентов

## 🔧 Разворачивание

- `_делаем.md` — появилась текущая работа по проекту
- `_планы.md` — появились отложенные задачи и идеи
- `_хроника.md` — стоит записать, что происходило
- `_решения.md` — первое значимое решение по проекту
- `люди-{имя}.md` — `люди.md` разросся: отдельный профиль человека
- `_встречи/` — правило встреч из корневого README размещает встречи здесь; одна встреча — одна папка
- `deliverables/` — появились материалы для контрагента
- `docs/` — юридические и исходные документы проекта
- Служебные папки (`_входящее/`, `_архив/`) — по потоку неразобранного и архива
