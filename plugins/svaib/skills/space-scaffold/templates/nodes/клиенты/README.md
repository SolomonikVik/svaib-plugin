# клиенты — клиентский портфель

Родительский объект управления для портфеля клиентов: появляется, когда клиентскими отношениями управляют отдельно — есть свой ответственный, метрики и ритуалы.

## Содержимое папки

- [_вводная.md](_вводная.md) — вводная клиентского портфеля: что это, кто отвечает, куда идёт и почему. Читать: при первичном входе в портфель.
- `{имя-клиента}/` — папка одного клиентского проекта: контрагент, проект и операционная работа. Читать: когда нужна память этого внешнего проекта.

## Связанные контексты

- `../00_компания/` — компания как целое, если клиентский портфель связан с общими целями или метриками

## 🔧 Разворачивание

- Новые клиентские проекты — по шаблону `client-name/`, папка называется именем клиента
- Остальные обзорные файлы, папки управления, служебные папки, обычные папки клиента — по живой работе портфеля
