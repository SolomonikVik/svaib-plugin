# 00_показатели — показатели компании

Показатели компании — папка управления ракурса «Цели и показатели»: какие ключевые показатели бизнеса важны, что они значат, где источник и как читать состояние. Целевые значения — в `цели.md`.

## Содержимое папки

- [ключевые-показатели.md](ключевые-показатели.md) — ключевые бизнес-метрики компании: семантика, источники, правила чтения. Читать: при вопросах о цифрах и состоянии бизнеса.

## Связанные контексты

- [цели.md](../00_стратегия/цели.md) — цели компании, с которыми сверяются метрики

## 🔧 Разворачивание

- `показатели-{направления}.md` — появились метрики отдельной бизнес-области уровня компании
- `источники/` — значения метрик живут в файлах рядом со scaffold: xlsx, выгрузки, экспорты
- `extractors/` — нужны процедуры извлечения значений из локальных источников
