# 00_компания — компания как целое

Папка компании как целого: курс компании, общая команда, ключевые бизнес-метрики и кросс-функциональный контекст без более узкого владельца.

## Содержимое папки

- [00_стратегия/](00_стратегия/) — папка управления «стратегия»: курс и стратегические выборы. Вводной у компании нет — её роль играют видение, цели и стратегия. Старт: [видение.md](00_стратегия/видение.md), [цели.md](00_стратегия/цели.md). Читать: первым, чтобы войти в контекст компании.
- [00_команда/](00_команда/) — папка управления «команда»: общая команда, роли, ответственность. Старт: [оргструктура.md](00_команда/оргструктура.md). Читать: при вопросах о людях, ролях и ответственных.
- [00_показатели/](00_показатели/) — папка управления «показатели»: ключевые бизнес-метрики и источники. Старт: [ключевые-показатели.md](00_показатели/ключевые-показатели.md). Читать: при вопросах о цифрах и состоянии бизнеса.
- [_входящее/](_входящее/) — входящее на разбор уровня компании. Читать: когда материал ещё не разложен по местам.
- [_архив/](_архив/) — холодный или завершённый контекст уровня компании. Читать: когда нужно найти старые материалы без смешивания с актуальным.

## 🔧 Разворачивание

- `_делаем.md` — появилась текущая кросс-функциональная работа
- `_планы.md` — появились отложенные задачи и идеи уровня компании
- `_хроника.md` — стоит записать, что происходило
- `_решения.md` — первое зафиксированное решение уровня компании
- Новые ракурсы (`00_финансы/`, `00_проекты/`, `00_процессы/`) — когда появилась работа по ракурсу: сразу папкой, даже ради одного файла
- `_встречи/` — правило встреч из корневого README размещает встречи здесь
- Смысловые файлы (`глоссарий.md`, `speech-aliases.md`) — по живой потребности
- Рабочие папки клиента (`docs/` и др.) — появились материалы уровня компании
