# Управленческое пространство руководителя — каркас папок и файлов

Карта управления бизнесом для работы с AI: компания, направления, входящее и архив. Точка входа — отсюда агент понимает, что читать и куда складывать новое.

## Содержимое папки

- [00_компания/](00_компания/) — компания как целое: курс, команда, ключевые метрики и кросс-функциональный контекст без более узкого владельца. Читать: всегда при входе, чтобы понять состояние и курс бизнеса.
- [_входящее/](_входящее/) — входящее на разбор: материал без места в дереве. Не источник правды — записи уходят на свои места. Читать: когда у материала ещё нет места.
- [_архив/](_архив/) — холодный и завершённый контекст. Читать: когда нужны старые материалы без смешивания с актуальным.
- [.svaib/](.svaib/README.md) — служебная папка помощника: правила работы агента на всё управленческое пространство, находки о расхождениях с каноном и учёт использования скиллов. Не про бизнес. Читать: хранителю канона и скиллам, которые пишут находки; руководителю — по желанию.

## Маршруты чтения

- Понять состояние и курс бизнеса → `00_компания/` (`00_стратегия/` — курс, `00_показатели/` — показатели)
- Работа по конкретному направлению → его папка в корне
- Разобрать неразложенный материал → `_входящее/`
- Создать новое направление, файл или папку → по шаблону скилла `space-scaffold`
- Записать или разобрать находку о расхождении пространства с каноном → [.svaib/findings.md](.svaib/findings.md), контракт в [.svaib/README.md](.svaib/README.md)
- Задать или поправить правила работы агента на всё пространство → `.svaib/rules.md`, назначение в [.svaib/README.md](.svaib/README.md)

## Связанные контексты

- Заполняется при разворачивании: внешние системы и контексты клиента, нужные для чтения этой карты.

## 🔧 Разворачивание

- Новое направление, продукт или клиенты — когда появляется объект, которым управляют отдельно
- Правило встреч (строка в «Правилах работы») — когда с руководителем согласовано размещение встреч
- Рабочие папки (`docs/`, `contracts/` и др.) — для материалов верхнего уровня
