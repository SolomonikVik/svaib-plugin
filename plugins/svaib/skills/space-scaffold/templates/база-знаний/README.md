# база-знаний — карта знаний

Обычная папка, не папка управления: здесь хранится обработанное знание, на которое объект управления опирается: объяснения, инсайты, конспекты, материалы и связи между темами.

Канон папки знаний в разработке. Базовая форма на сейчас: страницы и разделы по темам; неразобранное живёт во входящем.

## Содержимое папки

- `{topic}.md` — страница знания по теме, которую объект управления переиспользует. Читать: когда нужно понять устойчивую тему, метод, правило или контекст.

## Маршруты чтения

- Найти устойчивое знание объекта управления → страницу или раздел по теме
- Понять, куда класть неразобранное → README родительского объекта управления и `_входящее/`; в `база-знаний/` его не храним

## Связанные контексты

- `../00_процессы/` — регламенты и повторяемая работа
- `../_входящее/` — неразобранное

## 🔧 Разворачивание

- `{topic}/` — одиночный файл перестал вмещать материалы и связи: тема разворачивается в раздел. По умолчанию раздел — не управленческий узел; по шаблону `unit/` — только если темой стали управлять как самостоятельным объектом.
