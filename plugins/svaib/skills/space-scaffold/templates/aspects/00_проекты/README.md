# 00_проекты — карта проектов

В ракурсе проектов хранятся временные инициативы объекта управления: проекты с ответственным, горизонтом, рабочей повесткой и завершением.

## Содержимое папки

- `{project-name}/` — папка проекта с README, обзорными файлами по потребности, встречами и рабочими материалами. Читать: когда по проекту началась регулярная работа.

## Маршруты чтения

- Найти активный проект объекта управления → README нужного `{project-name}/`
- Понять, где хранить новый проект → эту карту и README родительского объекта управления

## Связанные контексты

- `{unit}/_делаем.md` — текущая работа объекта управления, если проект ещё не выделен в отдельную папку
- `{unit}/_хроника.md` — что происходило у объекта, если проект на него влияет

## 🔧 Разворачивание

- `{project-name}/` — по проекту началась реальная работа: есть ответственный, горизонт, задачи, встречи или решения. Разворачивается по образцу направления: README + `_вводная`, дальше по живой работе проекта. Идея без регулярной работы остаётся в `_планы.md` объекта управления.
