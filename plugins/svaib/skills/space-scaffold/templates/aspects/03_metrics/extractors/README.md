# extractors — извлечение значений метрик

Местные процедуры и настройки, если они нужны для чтения источников метрик. Возвращают сырые значения с метаданными без расчёта производных показателей.

## Содержимое папки

- `{source-id}-extractor.*` — код извлечения значений из конкретного источника. Читать: когда нужно получить или проверить фактические значения метрик.

## Правила работы

- Для источника можно использовать общий читатель, коннектор или местную реализацию; отдельный extractor на каждый источник необязателен.
- Extractor возвращает сырые значения и метаданные: период, источник, timestamp, confidence, если нужен.
- Производные показатели и бизнес-интерпретация не живут здесь: они описываются в metrics-файлах и аналитических процедурах.
- Код extractor — наша зона ответственности; источник клиента в `../source/` остаётся read-only.
