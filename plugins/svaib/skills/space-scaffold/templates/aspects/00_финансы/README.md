# 00_финансы — карта финансов

В ракурсе финансов хранится финансовая модель объекта управления: как он зарабатывает, как считается рентабельность, какие направления зарабатывают, а в какие вкладываем. Цифры — бюджет, план и факт — живут в источниках, здесь — ссылки на них.

Канон ракурса финансов в разработке.

## Содержимое папки

- `{topic}.md` — одна финансовая тема объекта управления. Читать: когда нужно понять, как объект зарабатывает и как считаются его деньги.

## Маршруты чтения

- Найти значения → источник по ссылке из файла темы; целевые значения — `цели.md` объекта управления

## Связанные контексты

- `../00_показатели/` — показатели, в том числе финансовые, если они ведутся там

## 🔧 Разворачивание

- Обзорные файлы (`_вводная.md`, `_делаем.md` и др.) — финансами стали управлять отдельно: есть ответственный и регулярная работа. Тогда `00_финансы/` — объект управления, имя не меняется, README по шаблону `unit/`.
