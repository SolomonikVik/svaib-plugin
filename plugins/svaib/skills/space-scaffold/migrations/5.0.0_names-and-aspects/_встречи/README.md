# _встречи — память встреч

Папка памяти встреч. Одна встреча — одна папка; решения, задачи и факты из встречи живут на своих местах, здесь — сама встреча.

## Содержимое папки

Индекс встреч: строка на встречу, свежие сверху, ~10 слов о главном.

## Папка встречи

Имя: `ГГГГ-ММ-ДД_{[периодичность-]тип[-объект]}[_{тема}]/`, слова — в порядке речи: `2026-08-27_еженедельная-планерка-продукта_релиз-0-5`. Обязательны дата и тип; остальное пишется, только если не выводится из контекста:

- периодичность — только у регулярной встречи: ежедневная, еженедельная, ежемесячная, квартальная, полугодовая, годовая; согласуется с типом: `квартальные-итоги`;
- объект — если его не задаёт папка: в `{имя}/_встречи/` имя не повторяем, в общей папке пишем;
- тема — чтобы различить похожие встречи или когда тема главная.

Внутри — файлы с фиксированными именами: `повестка.md`, `транскрипт.md` (разговор текстом), `саммари.md` (что было на встрече — источник правды о ней), `протокол.md` (для участников). Лежит только то, что у встречи есть.

Тип — зачем собирались; тем же словом он пишется в шапке саммари:

| Тип | Что за встреча |
|---|---|
| `планерка` | состояние работы, блокеры, следующие шаги |
| `один-на-один` | руководитель и сотрудник: обратная связь, развитие, сложности |
| `итоги` | итоги периода или проекта против плана |
| `стратсессия` | направление, цели, ставки, приоритеты |
| `мозговой-штурм` | идеи к одной задаче; идеи не становятся задачами сами |
| `переговоры` | переговоры об условиях со стороной с другими интересами |
| `собеседование` | собеседование кандидата |
| `встреча` | тип не определить или форматов несколько |

Новый тип добавляет человек; агент тип не придумывает — берёт `встреча`.

Подпапка внутри `_встречи/` (`один-на-один/`, `квартальные-итоги/`) — когда здесь живут несколько серий или встреч слишком много.

## Маршруты записи

- Материалы встречи → её папка; строка о встрече → индекс выше
- Решения, задачи и факты из встречи → канонические файлы своих узлов, если они развёрнуты

## Связанные контексты

- `../README.md` — родительский узел этой папки встреч
- `../_делаем.md` — задачи и открытые вопросы после встречи, если файл развёрнут
- `../_хроника.md` — что происходило у объекта, если файл развёрнут
- `../_решения.md` — решения, принятые на встрече, если файл развёрнут
