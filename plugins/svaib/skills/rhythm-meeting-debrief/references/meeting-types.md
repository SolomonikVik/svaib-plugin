# Типы встреч — словарь, периодичность, имя папки встречи

Тип — метка встречи: зачем собираемся. Живёт в имени папки встречи и в шапке саммари — одним и тем же словом.

## Имя папки встречи

```text
ГГГГ-ММ-ДД_{[периодичность-]тип[-объект]}[_{тема}]/
```

Слова — в порядке речи. Обязательны дата и тип. Остальное пишется, только если не выводится из контекста:

- периодичность — только у регулярных встреч, согласуется с типом: `квартальные-итоги`;
- объект — только если не задан папкой: внутри `<объект>/_встречи/` имя объекта не повторяем, в общей папке пишем;
- тема — чтобы различить две похожие встречи или когда тема доминирует.

Примеры:

```text
2026-08-27_еженедельная-планерка-продукта_релиз-0-5/  # все поля: регулярная планёрка продукта, тема — релиз 0.5
2026-08-26_переговоры-акме/                          # в клиенты/_встречи/: разовые переговоры с клиентом «Акме»
2026-08-26_мозговой-штурм/                           # в продукт/_встречи/: объект задан путём, встреча разовая
```

Имя — ярлык для человека; машинная истина — шапка саммари (`саммари.md`).

## Периодичность

Периодичность (ритм встреч) — свойство серии регулярных встреч, не тип. У разовой встречи периодичности нет.

Значения: ежедневная · еженедельная · ежемесячная · квартальная · полугодовая · годовая.

## Словарь типов

| Тип | Английский вариант | Определение |
|---|---|---|
| `планерка` | `sync` | Обычно регулярная встреча команды или участников проекта. Сверяют состояние текущей работы, обсуждают результаты, блокеры и зависимости, договариваются о следующих действиях. |
| `один-на-один` | `one-to-one` | Регулярный разговор руководителя с сотрудником об обратной связи, развитии, текущих сложностях и отношениях. Не любая встреча двух людей и не собеседование. |
| `итоги` | `review` | Сравнивают результаты периода или проекта с планом и ожиданиями, разбирают причины отклонений и при необходимости меняют план или правила. Примеры: ретроспектива, месячные или квартальные итоги. |
| `стратсессия` | `strategy` | Выбирают направление, цели, ключевые ставки, приоритеты и ограничения. Примеры: годовая или квартальная стратсессия, выбор продуктового направления. |
| `мозговой-штурм` | `brainstorm` | Генерируют разные идеи и возможные решения одной задачи. На самой встрече выбирать окончательное решение необязательно. Высказанные идеи не становятся задачами автоматически. |
| `переговоры` | `negotiation` | Стороны с разными интересами согласуют условия: цену, объём, сроки, ответственность и другие параметры сотрудничества. |
| `собеседование` | `interview` | Компания оценивает кандидата на соответствие роли. Примеры: первичное, профессиональное и финальное интервью. |
| `встреча` | `general` | Тип по умолчанию, когда тип определить нельзя или во встрече нет одного преобладающего формата. |

Новый тип добавляет человек; агент тип не придумывает — берёт `встреча`.
