# Партнёр svaib по почте

Партнёру можно написать на **partner@svaib.com**, ответить на его письмо или переслать ему письмо с задачей. Он использует доступное вам пространство компании и отвечает на ваш подключённый адрес.

## Что можно делать

| Действие | Как работает |
| --- | --- |
| Задать новый вопрос | Отправьте отдельное письмо партнёру |
| Продолжить разговор | Ответьте в существующей цепочке: партнёр учитывает её историю |
| Разобрать чужое письмо | Перешлите его с текстом письма и добавьте, что нужно сделать: разобрать, предложить ответ, выделить задачи |
| Получить результат из Telegram | Попросите «пришли этот результат мне на почту» |
| Отправить результат с рабочего места | MCP-инструмент `send_email_message` отправляет выбранный текст вам |

Каждая почтовая цепочка имеет свою историю. Совпадение темы само по себе не объединяет разговоры; для продолжения используйте ответ в цепочке. Переписка из Telegram автоматически в почтовую историю не переносится. Письма сохраняют отдельную историю разговора и не заменяют файлы пространства.

## Адрес и доступ

Почта должна быть включена для компании, а ваш адрес — подтверждён. При доступном самостоятельном подключении агент рабочего места запрашивает код через MCP и принимает его от вас; иначе подключение выполняет сопровождение платформы. Поле `email` в карточке само по себе этого не делает. Смена или очистка поля отзывает прежнюю привязку; новый адрес нужно подтвердить заново. Партнёр определяет права по подключённому отправителю; автор пересланного текста не получает доступ к пространству.

Отправка из Telegram и MCP идёт только на собственный подтверждённый адрес. Произвольных адресатов и рассылки участникам в этих инструментах нет. Как подключиться — в [инструкции](email.md).

## Оформление и ограничения

Ответ приходит с HTML-оформлением и текстовой версией: заголовки, выделения, списки, ссылки, таблицы и блоки кода. Для MCP тема ограничена 200 символами, текст — 32768 байт UTF-8; кириллица занимает больше одного байта на символ. При превышении лимита сервер сообщает размер и предел, не обрезает текст сам.

Проверенный пользовательский путь пересылки — текст письма внутри пересылки. PDF, Office, изображения и OCR не входят в текущую возможность. Живая обработка вложенного `.eml` не принята как проверенный пользовательский сценарий.

Постановка в очередь не означает получение во входящих. При неопределённом исходе повтор с новым ключом может создать дубликат; обратитесь к оператору. [Контракт MCP](https://github.com/SolomonikVik/svaib/blob/v0.11.0/product/docs/mcp-platform.md#%D0%BF%D0%BE%D1%87%D1%82%D0%B0-%D0%BF%D0%B0%D1%80%D1%82%D0%BD%D1%91%D1%80%D0%B0-%D0%B8-mcp-%D0%BE%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D0%BA%D0%B0) описывает аргументы и безопасный повтор.
