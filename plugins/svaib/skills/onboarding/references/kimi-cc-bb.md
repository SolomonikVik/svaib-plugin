# Подключение Kimi к Claude Code в BB

Для нового пользователя из России рекомендуем **BB + Kimi через Claude Code**: зарубежная карта и VPN для этого пути не нужны. В BB провайдер называется **Kimi (CC)**. Если подходящий агент уже работает, сохраняем его; заново покупать подписку и менять рабочую связку не требуется.

Сначала Telegram-помощник помогает установить BB и получить первый ответ модели. После этого агент BB выполняет техническую настройку svaib. Бесплатная оболочка BB сама по себе не даёт доступа к модели.

## 🔹 Подписка и ключ

1. Открой международный [сайт Kimi](https://www.kimi.com) и войди в свой аккаунт. Один из способов — Google.
2. Открой [подписку](https://www.kimi.com/settings/subscription). Для Kimi K3.1 Pro с контекстом 1M выбираем **Pro**; ориентир на 2026-11-05 — **$39 в месяц**. Перед оплатой проверь цену и доступные возможности в своём аккаунте. Plus тоже даёт Kimi Code, но для K3.1 Pro ограничивает контекст до 256K; Go не даёт coding-квоту.
3. Для оплаты картой «Мир» используй сайт Kimi с российским IP и выключенным VPN. Если способ оплаты не появился или платёж отклонён, сообщи помощнику, что показано на экране; не покупай другую подписку наугад.
4. В [консоли Kimi Code](https://www.kimi.com/code/console) создай API-ключ и сохрани его локально. Нужен именно ключ Kimi Code, а не отдельного сервиса Kimi Open Platform.

Ключ вводится скрыто в локальном настройщике. Не вставляй его в Telegram, текст разговора BB, скриншот или JSON настроек провайдера.

## 🔹 Если в BB уже работает агент

Открой обычный разговор в BB и попроси:

> Подключи Kimi через Claude Code по инструкции svaib. Сохрани действующие провайдеры и входы; ключ запроси защищённым локальным вводом.

Агент проверит текущие настройки, подготовит отдельный профиль и проверит ответ модели. Если Kimi (CC) уже работает, повторная установка не нужна. Готовность подключения svaib проверяется отдельно.

## 🔹 Если в BB ещё нет работающего агента

Здесь нужен ручной первый запуск: некому выполнять команды, пока модель ещё не отвечает. Telegram-помощник ведёт по одному действию. После первого ответа модели техническую работу берёт агент BB.

1. Установи и открой [BB](bb-and-omp.md). В мастере можно пропустить выбор агента через **Skip** и закончить **Start using bb**. Подписку Claude или ChatGPT для Kimi покупать не нужно.
2. Установи **Node.js 22 или новее** с [официального сайта](https://nodejs.org/en/download), оставив npm в составе установки. Затем открой новый Terminal на Mac/Linux или PowerShell на Windows.
3. Скачай [настройщик Kimi для BB](https://github.com/SolomonikVik/svaib-bb/raw/refs/heads/main/scripts/setup-kimi-cc.mjs) в папку **Downloads / Загрузки**. Имя файла — `setup-kimi-cc.mjs`, без добавленного `.txt`. Если ссылка недоступна, попроси помощника дать проверенный файл; случайный скрипт вместо него не используй.
4. Запусти настройщик одной командой для своей ОС.

**Mac / Linux:**

```bash
node "$HOME/Downloads/setup-kimi-cc.mjs"
```

**Windows, PowerShell:**

```powershell
node "$env:USERPROFILE\Downloads\setup-kimi-cc.mjs"
```

5. Когда настройщик запросит ключ Kimi Code, вставь его локально и нажми Enter. Символы не отображаются. Дождись сообщения «Профиль подготовлен» и блока настроек без ключа.
6. В BB открой **Settings → Plugins → ACP providers → Custom agents**. При первом запуске список пуст: вставь выданный настройщиком массив целиком и сохрани. Если записи уже есть, не заменяй их: передай помощнику задачу добавить Kimi с сохранением существующих настроек. Значения ключей ему не отправляй.
7. Открой обычный новый разговор, выбери **Kimi (CC)** и **Kimi K3.1 Pro (1M)**. Отправь короткий вопрос и дождись ответа.

Настройщик устанавливает актуальный ACP-адаптер и его Claude CLI в отдельную локальную папку. Глобальный профиль Claude и другие провайдеры он не меняет. Если установка прервётся, сообщи помощнику текст ошибки без ключа; повторный запуск не перезаписывает сохранённый профиль.

**Результат:** в BB получен реальный ответ модели. Список моделей или сообщение об установке сами по себе этого не подтверждают.

## 🔹 Подключить svaib

После первого ответа передай агенту BB запрос Telegram-помощника и продолжи по [маршруту подключения svaib](bb-svaib.md). Сохраняются исходное поручение, компания, выбранная папка и уже работающий доступ к модели.

Агент проверяет отдельно: пакет svaib для Claude Code в том же профиле Kimi, работу MCP, запуск хуков, затем пространство и знакомство. Простой ответ Kimi ещё не подтверждает эти результаты.

## 🔹 Агенту: профиль и проверка

Текущий настройщик использует `@agentclientprotocol/claude-agent-acp@0.100.0`. Прежний `@zed-industries/claude-code-acp` переименован; новый запуск на нём не строим. Модель BB и binding сохраняются как `acp-claude-kimi`; вариант методологического пакета — `claude`. Не подменяй provider ID на `claude-code`.

Профиль настройщика — `~/.bb/providers/kimi-cc/` (Windows: `%USERPROFILE%\.bb\providers\kimi-cc\`): `claude/` — изолированный `CLAUDE_CONFIG_DIR`, `credentials.json` — закрытый файл ключа, `launch.mjs` — запуск, `bb-agent.json` — регистрация без секретов. Запуск Claude CLI с тем же профилем: `node <абсолютный путь launch.mjs> --claude <аргументы CLI>`. Плагин/MCP ставь только через этот CLI и профиль, не через первый `claude` из PATH. Для существующей настройки сначала выясни её фактические пути; новый профиль молча не создавай.

Официальный профиль для 1M использует `k3.1-pro[1m]`, соответствующие лимиты контекста и сжатия и mapping фоновых моделей. Thinking должен оставаться включённым. Настройщик ограничивает каталог основной моделью; число доступных моделей не является признаком готовности. Право на 1M зависит от подписки, а не от подписи в списке BB.

## 🔹 Если что-то пошло не так

- **429:** прочитай текст ошибки. Это могут быть пять часов, месячная квота, недельная квота старого тарифа, параллельные запросы или перегрузка сервера. Extra Usage нужен при исчерпанной квоте; при перегрузке подожди и повтори, покупка её не исправит.
- **403 про модель или 1M:** проверь возможности подписки и выбранную модель; имя в BB не даёт права на неё.
- **Провайдер не появился:** проверь сохранение записи в ACP providers и завершение настройки. Не переустанавливай весь BB.
- **Модель представилась Claude:** самоописание не доказывает маршрут запроса. Агент проверяет локальный профиль и доступ к Kimi, не выводя ключ.
