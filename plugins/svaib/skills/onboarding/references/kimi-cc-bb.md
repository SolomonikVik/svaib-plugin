# Подключение Kimi к Claude Code в BB

Для нового пользователя из России рекомендуем **BB + Kimi через Claude Code**: зарубежная карта и VPN для этого пути не нужны. В BB провайдер называется **Kimi (CC)**. Если подходящий агент уже работает, сохраняем его; заново покупать подписку и менять рабочую связку не требуется.

Сначала обсуди с Telegram-помощником варианты и выбери подходящий. Если уже работает Codex, Claude или другой подходящий агент, можно продолжить с ним без новой покупки. Для выбранного Kimi помощник помогает установить BB и плагин svaib, пройти встроенный настройщик и получить первый ответ модели. После этого агент BB продолжает подключение svaib. Бесплатная оболочка BB сама по себе не даёт доступа к модели.

## 🔹 Подписка и ключ

1. Открой международный [сайт Kimi](https://www.kimi.com) и войди в свой аккаунт. Один из способов — Google.
2. Открой [подписку](https://www.kimi.com/settings/subscription). Настройщик использует Kimi K3.1 Pro с контекстом 1M — для него подходит **Pro** или выше. Plus тоже даёт Kimi Code, но не 1M для этой модели; Go не даёт coding-квоту. Перед оплатой проверь текущую цену, возможности и квоту в своём аккаунте. Рабочую прежнюю подписку не меняй только ради названия тарифа.
3. Для оплаты картой «Мир» проверь доступный способ на сайте Kimi с российским IP и выключенным VPN. Наличие способа и успешность платежа подтверждаются на экране оплаты, не этой инструкцией. Если способ не появился или платёж отклонён, сообщи помощнику, что показано; не покупай другую подписку наугад.
4. В [консоли Kimi Code](https://www.kimi.com/code/console) создай API-ключ и сохрани его локально. Нужен именно ключ Kimi Code, а не отдельного сервиса Kimi Open Platform.

Ключ вводится в защищённом поле карточки BB-плагина. Не вставляй его в Telegram, текст разговора BB, скриншот или JSON настроек провайдера.

## 🔹 Если в BB уже работает агент

Если этот доступ подходит, сохрани его и продолжи подключение svaib. Настройку Kimi выполняй только если выбрал добавить его. В этом случае можно открыть встроенную карточку ниже или попросить доступного агента помочь:

> Подключи Kimi через Claude Code по инструкции svaib. Сохрани действующие провайдеры и входы; ключ запроси защищённым локальным вводом.

Агент проверит текущие настройки и поможет пройти тот же встроенный маршрут с сохранением существующего доступа. Если Kimi (CC) уже работает, повторная установка не нужна. Готовность подключения svaib проверяется отдельно.

## 🔹 Настройка из интерфейса плагина

Основной путь — опубликованный плагин **svaib для BB0.4.0 или новее** со встроенной карточкой Kimi. Для установки плагина, подготовки модели и ввода ключа готовый агент и вход в svaib не нужны. Версия плагина отличается от версии самого BB Desktop.

1. В BB установи расширение [svaib](https://github.com/SolomonikVik/svaib-bb) через **Settings → Installed plugins → New plugin → Install from source**. Работающий агент для установки расширения не нужен.
2. Открой страницу svaib и нажми **«Настроить Kimi»**. Вход в аккаунт svaib пока не требуется.
3. Если плагин сообщит, что не хватает Node.js, установи его с npm по показанной ссылке и нажми **«Проверить установку»**. Остальную подготовку выполняет плагин.
4. Вставь ключ из консоли Kimi Code в защищённое поле карточки и нажми **«Подготовить подключение»**. Профиль и адаптер будут установлены отдельно от действующих подключений.
5. Плагин добавит Kimi через доступный API BB. Если операция недоступна, карточка покажет запись без ключа и действие в ACP providers. Существующие записи сохраняй.
6. В показанном поле нового разговора проверь выбранные Kimi (CC) и компьютер, затем отправь готовый короткий запрос. После проверенного ответа карточка исчезнет. Подключение svaib продолжается отдельно.

Если используешь другого агента, выбери **«У меня уже есть другой агент»**. **«Не сейчас»** тоже скрывает карточку. Повторное открытие — в настройках плагина, **«Настроить или проверить Kimi»**. Новый чат и перезапуск BB сами её не возвращают.

Нет карточки — открой из настроек; нет и этого действия — проверь версию и обнови плагин из того же источника. Не переустанавливай Kimi из-за скрытой карточки. Ошибку установки продолжай с текущего шага; свой ошибочный ключ исправляй в карточке. Действующие подключения сохраняются.

## 🔹 Подключить svaib

После ответа из карточки открой обычный новый разговор BB с тем же Kimi (CC) и выбранной рабочей папкой. Служебный разговор «Проверка Kimi» ограничен коротким тестом — настройку svaib в нём не продолжай. Передай запрос Telegram-помощника в обычный разговор и продолжи по [маршруту подключения svaib](bb-svaib.md). Доступ, профиль, исходное поручение, компания и папка сохраняются; повторный тест модели не нужен.

Агент проверяет отдельно: пакет svaib для Claude Code в том же профиле Kimi, работу MCP, запуск хуков, затем пространство и знакомство. Простой ответ Kimi ещё не подтверждает эти результаты.

## 🔹 Агенту: профиль и проверка

Опубликованный настройщик использует `@agentclientprotocol/claude-agent-acp@0.100.0`. Provider BB — `acp-claude-kimi`, модель сохраняет настоящий ID. Методологический пакет svaib общий для Codex и Claude Code; для Kimi выбирается CLI/profile Claude. Не подменяй provider ID на `claude-code`.

Карточка использует собственный каталог данных BB-плагина на компьютере. У ранее настроенного подключения каталог может отличаться; путь не угадывай. Возьми command/args действующей регистрации Kimi в BB, установи настоящий `launch.mjs` и его изолированный `CLAUDE_CONFIG_DIR`. Внутри профиля `claude/` содержит конфигурацию, `credentials.json` — закрытый ключ, `bb-agent.json` — регистрацию без секретов; ключи не читай и не выводи.

Claude CLI запускается в том же профиле: `node <проверенный абсолютный launch.mjs> --claude <аргументы CLI>`. Методологический плагин/MCP ставь через него, не через первый `claude` из PATH. Существующий launcher не заменяй и новый профиль молча не создавай. Успех карточки подтверждает ответ модели, а native MCP, хуки и вход в svaib проверяются отдельно.

Официальный профиль для 1M использует `k3.1-pro[1m]`, соответствующие лимиты контекста и сжатия и mapping фоновых моделей. Thinking должен оставаться включённым. Настройщик ограничивает каталог основной моделью; число доступных моделей не является признаком готовности. Право на 1M зависит от подписки, а не от подписи в списке BB.

## 🔹 Если что-то пошло не так

- **429:** прочитай текст ошибки. Это могут быть пять часов, месячная квота, недельная квота старого тарифа, параллельные запросы или перегрузка сервера. Extra Usage нужен при исчерпанной квоте; при перегрузке подожди и повтори, покупка её не исправит.
- **403 про модель или 1M:** проверь возможности подписки и выбранную модель; имя в BB не даёт права на неё.
- **Провайдер не появился:** проверь сохранение записи в ACP providers и завершение настройки. Не переустанавливай весь BB.
- **Модель представилась Claude:** самоописание не доказывает маршрут запроса. Агент проверяет локальный профиль и доступ к Kimi, не выводя ключ.
