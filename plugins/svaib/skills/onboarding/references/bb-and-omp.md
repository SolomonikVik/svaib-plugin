# Установка BB Desktop, Codex CLI и OMP

BB — приложение, в котором ты общаешься с агентом и работаешь с файлами компании. Для нового доступа из РФ рекомендуем [Kimi через Claude Code](kimi-cc-bb.md). Если человек выбрал другой подходящий вариант, сохраняем его. После установки BB подключаем плагин svaib через меню и настраиваем Kimi его встроенной карточкой; готовый агент для этого не нужен. Затем проверяем ответ модели. Если выбрал Pi или другие движки ограничены твоей ОС, продолжай по [инструкции Pi + Kimi](kimi-pi-bb.md); она укажет доступный способ настройки.

На Mac с Apple Silicon и на Windows основной способ установки — установщик и меню приложения. Для Intel Mac используй путь через Node.js и браузер ниже. Если экран отличается от описания, сообщи, что видишь.

В мастере **Agent → Projects → Plugins → Devices** переходи кнопкой **Continue**, необязательные настройки пропускай через **Skip**; в конце нажми **Start using bb**. Для Kimi пропусти выбор другого агента и следуй [инструкции Kimi](kimi-cc-bb.md). Для подписки Codex/Claude используй **Install**. При ошибке сообщи её помощнику. Desktop не требует терминала и npm; для Intel Mac путь ниже. Далее — [инструкция BB](bb-svaib.md).

## 🔹 Что скачать

Помощник проверит текущий официальный релиз через get_workplace_download и даст одну прямую ссылку для твоих ОС и архитектуры. Самостоятельно искать файл на GitHub не нужно. При ошибке проверки или неподдерживаемой архитектуре он поможет выбрать доступный путь, не подставляя другую сборку наугад. [Официальные варианты установки](https://github.com/get-bb/bb#download-the-desktop-app).

На выданном командой виртуальном Linux-столе тоже используем Desktop/AppImage. Сохраняем скачанное приложение и уже выполненные шаги.

## 🔹 Mac: Apple Silicon

1. В меню Apple → «Об этом Mac» проверь поле «Чип».
2. Скачай BB по прямой ссылке помощника для этого Mac.
3. Открой DMG и перенеси BB в Applications («Программы»).
4. Запусти BB из Applications.
5. Для нового доступа из РФ продолжи по [инструкции Kimi](kimi-cc-bb.md). Если подходящий агент уже работает, сохрани его.
6. Для отдельно выбранной подписки Codex/Claude установи агента кнопкой **Install** и подтверди вход в браузере. Если BB попросит дополнительный компонент, передай помощнику текст запроса.

BB Desktop не требует отдельной установки Node.js для оболочки. [Способы установки BB](https://github.com/get-bb/bb#use-bb).

## 🔹 Mac: Intel и браузер

На macOS 11 пользователь подтвердил, что Pi запускается и обнаруживается в BB; весь путь подключения svaib на этой ОС ещё проверяется. Для модели используй [Pi + Kimi](kimi-pi-bb.md). Установи [Node.js 22](https://nodejs.org/dist/latest-v22.x/) через `.pkg` (от 22.19). В «Терминале» проверь `git --version`; если Git нет, выполни `xcode-select --install` и заверши установку. Запусти `npx bb-app@latest` и открой `http://localhost:38886` на том же Mac. Оставь терминал открытым; Ctrl+C остановит BB. При ошибке пришли её текст помощнику. Далее — [подключение svaib](bb-svaib.md). [Источник BB](https://github.com/get-bb/bb/tree/main/packages/bb-app#install-and-run).

## 🔹 Windows: Desktop

1. Используй Windows x64; проверенный upstream-маршрут — Windows 11.
2. Скачай BB по прямой ссылке помощника для Windows.
3. Открой скачанный `.exe`.
4. Запусти установщик, закончи установку и открой BB из меню «Пуск».
5. Для нового доступа из РФ продолжи по [инструкции Kimi](kimi-cc-bb.md). Для отдельно выбранной подписки Codex/Claude используй штатную кнопку **Install** и подтверди вход в браузере.
6. Для первого проекта используй обычную локальную папку. UNC-пути `\\server\share` BB отвергает.

Если BB сообщает об отсутствии Git, установи [Git for Windows](https://git-scm.com/download/win) через обычный установщик и снова открой BB. Проверки в PowerShell для этого не нужны. [Поддерживаемые рабочие среды](https://github.com/get-bb/bb/blob/main/docs/platform-support.md#supported-host-environments).

## 🔹 Linux: Desktop AppImage

1. Скачай AppImage по прямой ссылке помощника для Linux.
2. В свойствах файла разреши запуск как программы и открой его. Если файловый менеджер не предлагает такой настройки, помощник даст одну подходящую команду для твоей оболочки.
3. Для нового доступа из РФ продолжи по [инструкции Kimi](kimi-cc-bb.md). Для отдельно выбранной подписки установи агента штатной кнопкой **Install** и подтверди вход.

Для AppImage нужна библиотека FUSE 2. Если приложение сообщает об отсутствии `libfuse.so.2`, установи пакет этой библиотеки средствами своего дистрибутива. Пользовательские настройки и история BB по умолчанию хранятся в `~/.bb/`.

Ярлык в меню и другие удобства агент поможет настроить после первого работающего разговора.

## 🔹 Установка открытого харнеса Codex CLI

Этот раздел предназначен только для отдельно выбранной самостоятельной работы напрямую с CLI и для технического агента поддержки. Он не является запасным шагом обычной установки Desktop: при ошибке кнопки Install пользователь Mac/Windows остаётся с помощником на текущем шаге, без установки npm и команд в терминале. Если работаешь через BB, пропусти этот раздел.

Codex CLI — открытый компонент Codex, который BB запускает локально. [Открытые компоненты](https://learn.chatgpt.com/docs/open-source).

Используем официальный npm-пакет `@openai/codex` с тегом `latest`. Если Node.js и npm ещё нет, установи актуальную **Node.js LTS** через [официальную страницу загрузки](https://nodejs.org/en/download), затем открой новый терминал. Для Linux выбери предложенный на этой странице способ установки для своего дистрибутива. Проверь `node --version` и `npm --version`.

**Mac и Linux**, обычный терминал:

```bash
npm install -g @openai/codex@latest
codex --version
codex --help
```

**Windows**, обычный PowerShell:

```powershell
npm.cmd install -g @openai/codex@latest
codex.cmd --version
codex.cmd --help
```

На Windows `.cmd` запускает npm-обёртку без изменения политики PowerShell. После установки открой новый терминал; если команда не найдена, проверь, что каталог глобальных npm-команд доступен в PATH.

Для Linux/macOS глобальный npm-каталог должен быть доступен пользователю для записи. При `EACCES` настрой пользовательскую установку Node/npm и повтори команду. [Установка CLI в официальной документации OpenAI](https://learn.chatgpt.com/docs/codex/cli).

Установка завершена, когда CLI показывает версию и справку. Эти две проверки не отправляют запросов модели. На следующем этапе выбираем доступ к модели и способ авторизации; подписка не нужна для самой установки открытого CLI. Сторонние провайдеры подключаются через конфигурацию Codex. [Конфигурация провайдеров](https://learn.chatgpt.com/docs/config-file/config-advanced#custom-model-providers).

Для обновления повтори команду установки с `@latest`, проверь новую версию и перезапусти BB.

## 🔹 Подключение Codex к BB Desktop

1. Полностью закрой BB и снова открой его после установки харнеса.
2. Добавь локальную папку пространства как проект.
3. Открой новый тред и выбери **Codex**.
4. Настрой выбранную модель и провайдера, затем проверь один запрос с чтением локального файла. До этого доступ к модели считается неподтверждённым.

BB использует установленный CLI и его настройки. Плагин svaib устанавливается в харнес отдельным шагом. [Провайдеры BB](https://github.com/get-bb/bb/blob/main/packages/bb-app/README.md#provider-credentials).

## 🔹 OMP на Linux

Если Bun не установлен, выбираем официальный готовый бинарник. Он не требует отдельной установки Bun или npm-пакета; установщик проверяет SHA-256 и `--version` перед сообщением об успехе. [Установщик OMP](https://github.com/can1357/oh-my-pi/blob/main/scripts/install.sh).

```bash
curl -fsSL https://omp.sh/install -o /tmp/omp-install.sh
sh /tmp/omp-install.sh --binary
```

Проверка:

```bash
~/.local/bin/omp --version
~/.local/bin/omp --help
```

Справка и номер установленной версии должны выводиться без ошибки. Первый полноценный запуск распаковывает native-модули в `~/.omp/natives/`; каталог должен быть доступен пользователю для записи.

Если `command -v omp` ничего не показывает, добавь `export PATH="$HOME/.local/bin:$PATH"` в конфигурацию своего shell (`~/.bashrc` для bash), затем открой новый терминал. Саму установку выполняй без `sudo`.

Чтобы начать новый разговор, открой терминал в папке пространства и запусти `omp`. Авторизация провайдера — следующий отдельный шаг. Если актуальный Bun уже есть и нужен npm-путь расширений, upstream рекомендует `bun install -g @oh-my-pi/pi-coding-agent@latest`. Для Alpine/musl нужны также `libstdc++` и `libgcc`. [Варианты OMP](https://github.com/can1357/oh-my-pi/blob/main/README.md#install).

## 🔹 Признак готовности и следующий шаг

BB установлен, когда интерфейс открывается, локальный проект добавляется, а подготовленный харнес доступен для нового треда. Codex CLI и OMP установлены, когда версия и справка запускаются без ошибки. Эти проверки ещё не доказывают ответ реальной модели или работу svaib.

Далее отдельно проверяем доступность и оплату провайдера из России, подключение модели, установку методологического плагина, MCP-авторизацию, хуки и полный рабочий сценарий. Плагин интерфейса BB и пакет svaib для харнеса устанавливаются независимо. Одной успешной установки оболочки недостаточно для утверждения «работает без VPN и зарубежных карт».

Для маршрута через BB продолжай по [инструкции до первого разговора с партнёром](bb-svaib.md).
