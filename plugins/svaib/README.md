# Second Value AI Brain

Партнёр руководителя внутри его управленческого пространства: знает, как устроено пространство, помогает вести встречи, цели и показатели, держит порядок в базе.

## Что приехало

| Навык | Что делает |
| --- | --- |
| `rhythm-meeting-agenda` | Повестка к предстоящей встрече: что решать, где отклонения, какие вопросы вынести |
| `rhythm-meeting-debrief` | Разбор встречи: решения, договорённости, задачи — и обновление пространства по ним |
| `transcript-extract` | Выжимка из транскрипта разговора по темам |
| `content-update` | Обновление файлов пространства по итогам встречи или сессии |
| `metrics-values` | Живые значения показателей из книг руководителя: план, факт, динамика |
| `space-scaffold` | Устройство пространства: развернуть базу, поднять её версию, шаблоны и требования к типам файлов |
| `space-align` | Порядок в пространстве: расхождения с каноном и их исправление |
| `send-telegram` | Доставка результата в Telegram |
| `space-toolbox` | Внешние инструменты, которые можно подключить дополнительно |

Навык вызывается словами: «подготовь повестку к планёрке», «разбери эту встречу», «какая была маржа в июле». Точное имя знать не нужно.

## Что работает само

- **Карта пространства** — партнёр видит, как устроена база, и не ищет файлы наугад.
- **Требования к типам файлов** — перед записью он знает, каким файл должен стать.
- **Связь с платформой svaib** — узнаёт вас, доставляет сообщения, ведёт список участников. Требует однократной авторизации.

## Чего здесь нет

Внутренние инструменты команды svaib и навыки, сделанные под конкретную компанию: они приезжают отдельно и в этот пакет не входят.

## Как обновляется

Пакет обновляет сама среда — Claude Code или Codex. Структура пространства обновляется отдельно и только с вашего согласия: попросите партнёра проверить версию пространства.
