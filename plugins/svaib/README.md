# svaib — Second Value AI Brain

**AI-партнёр руководителя, который знает ваш бизнес и держит фокус на цели.**

svaib связывает цели, проекты, встречи, показатели и решения в управленческом пространстве —
документах и подключённых источниках вашего бизнеса. Работает с ними как партнёр: помнит
контекст, видит связи, которые легко упустить, и возвращает к цели. Этот плагин ставит
партнёра в Claude Code, Codex и Cowork.

**Статус — альфа.** Методология продолжает выверяться. История изменений — в [CHANGELOG](CHANGELOG.md).

## Роли партнёра

Партнёр сам подключает нужный взгляд по ходу разговора. В альфе доступны пять ролей:

- **Стратегия** — сверяет обсуждаемое с целями и стратегией компании и помогает их сформулировать.
- **Цели и показатели** — помогает ставить измеримые цели, выбирать показатели и оценивать движение по цифрам.
- **Команда** — помогает руководителю формировать и развивать команду, распределять ответственность.
- **Проекты** — помогает понять, нужен ли проект и движется ли он к нужному результату.
- **Ритм управления** — помогает выстроить встречи и отчёты так, чтобы целям, проектам и людям хватало внимания.

Например: «туда ли мы идём?», «как распределить ответственность?», «какие встречи нам нужны?».

## Что можно поручить

Скиллы вызываются обычными словами — их имена знать не нужно.

| Что | Как попросить |
|---|---|
| Повестка к встрече | «подготовь повестку к планёрке» |
| Разбор встречи и протокол | «разбери эту встречу» |
| Обновление документов по итогам | «обнови документацию по итогам сессии» |
| Выбор ключевых метрик | «какие показатели нам нужны, чтобы видеть движение к цели?» |
| Цифры метрик | «какая маржа в июле?», «выполняем план?» |
| Ревью проекта | «проведи ревью проекта за месяц» |
| Ревью подразделения | «как отдел продаж отработал квартал?» |
| Ревью человека | «подготовь ревью сотрудника за квартал» |
| Отправка в Telegram | «отправь мне это в телеграм» |

Для встречи партнёр собирает контекст до разговора и разбирает запись после него;
ревью проекта, подразделения или человека помогает перейти от результатов к решению.

Партнёр читает метрики, связывает их с целями и помогает проанализировать динамику.
Все расчёты производных значений выполняет детерминированно, подсвечивает пробелы в учёте.

## Как работает с пространством

Партнёр знает, где лежат цели, решения и договорённости, и сам поднимает нужный контекст.

- **Карта пространства** — партнёр видит структуру и не перебирает файлы наугад.
- **Требования к файлам** — перед записью знает, каким должен стать обзор, прогресс или журнал решений.
- **Поиск помощником** — обход папок идёт отдельно, основной разговор не забивается прочитанным.

Партнёр также разворачивает и обновляет пространство, разбирает накопленное без потери данных,
помогает подключить почту, календарь и документы. Можно попросить: «разверни пространство»,
«проверь версию пространства», «наведи порядок в папке продаж», «подключи календарь».

Через платформу svaib партнёр узнаёт вас в разных средах, доставляет сообщения и помнит
пройденные этапы освоения. На «где я?» подскажет следующий шаг; на «запомни, как со мной работать»
сохранит ваши личные настройки. Нужно один раз войти.

## Ваши данные и контроль

- Документы пространства — обычные Markdown-файлы в вашем хранилище: Google Диск или git.
  Их можно открыть, проверить и забрать целиком; таблицы и другие источники подключаются отдельно.
- Вы поручаете изменения и значимые действия. Если поручения ещё не было, партнёр сначала согласует их с вами.
- Учёт запусков скиллов пишется в ваше же пространство: модель, токены, время.
  Текста разговоров в учёте нет; сам учёт по сети не отправляется.
- Личные настройки и этапы освоения сохраняются на платформе svaib и доступны на другом рабочем месте.
- Модель и рабочую среду выбираете вы.

## Установка

### Claude Code

```bash
claude plugin marketplace add SolomonikVik/svaib-plugin
claude plugin install svaib@svaib
```

В сессии откройте `/plugin` → Marketplaces → `svaib` → Enable auto-update.
Автообновление сторонних маркетплейсов нужно включить вручную.
Порядок — в [документации Claude Code](https://code.claude.com/docs/en/discover-plugins#turn-auto-update-on-or-off-for-a-marketplace).

Если Claude Code запросит доступ к файлам плагина, подтвердите их чтение.

### Codex

```bash
codex plugin marketplace add https://github.com/SolomonikVik/svaib-plugin.git
codex plugin add svaib@svaib
```

Подтвердите доверие хукам плагина в настройках Codex: без этого карта пространства
и проверка требований к файлам не включатся.
После изменения хуков подтверждение может понадобиться снова
([документация OpenAI](https://developers.openai.com/plugins/build/plugins#bundled-mcp-servers-and-lifecycle-hooks)).

### Cowork

В Claude Desktop добавьте маркетплейс `SolomonikVik/svaib-plugin` и установите из него плагин `svaib`.
Для работы с локальной папкой выберите «Only on this computer» (Settings → Cowork):
хуки навигации и требований к файлам работают с пространством в этом режиме.
В облачном Cowork хуки не видят локальную папку; навигация опирается на инструкцию партнёра.
Можно также открыть папку пространства в режиме Code того же приложения.

## Первый запуск

Войдите в платформу svaib через подключение MCP.
Откройте папку, где будет жить пространство, начните новую сессию и скажите:
«онбординг, давай знакомиться». Партнёр проведёт через настройку рабочего места и пространства.

## Обновления

Плагин и структура пространства обновляются отдельно. Новые скиллы и исправления приходят
с обновлением плагина; изменения папок и правил пространства партнёр предлагает и согласует с вами.
Что изменилось в каждом выпуске — [CHANGELOG](CHANGELOG.md).
